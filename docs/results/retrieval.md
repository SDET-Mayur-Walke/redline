# Retrieval results

Generated by `scripts/eval_retrieval.py`: 27 hand-written customer questions, each labelled with the help doc(s) that answer it. Index: all 155 documents (help, staff, reviews). Dense `nomic-embed-text` via Ollama, sparse `Qdrant/bm25` with IDF, RRF (k=60) over top 20 from each, reranker `Xenova/ms-marco-MiniLM-L-6-v2`. Default config: chunk_tokens=150, rerank=false, index_metadata=true, staff_filter=false.

- **hit@5**: an answering doc is in the top 5.
- **MRR@5**: mean of 1/rank of the first answering doc (0 if not in the top 5).
- **staff@5**: share of these ordinary questions where a staff-only doc appears in the top 5.
  Nothing here is an attack, so this is the baseline leak exposure.
- **ms/query**: wall time per search on the M5, embeddings included.
