# Tracking your order

Open **My Orders** to see the status of every order. Order IDs start with "SC" followed by seven digits, for
example SC0100037.

## What each status means
| Status | Meaning |
|---|---|
| Pending | We've received the order and are packing it. You can still cancel it or change the address. |
| Shipped | It's with the courier. A tracking number is shown in the order details. |
| Delivered | The courier has marked it delivered. Your 10-day return window starts now. |
| Cancelled | The order was cancelled before it shipped. |
| Returned | We received the returned item and the refund has been issued. |

## The tracking page hasn't updated
Tracking updates when the parcel is scanned at a hub, so it can stay the same for a day while the parcel travels
between cities. If there's no update for 3 days, contact us and we'll check with the courier.

## Marked delivered but not received
Check with family members, neighbours and your building's security first. If you still can't find it, contact us
within 2 days of the delivery date and we'll open an investigation with the courier.
